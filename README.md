## 기술 스택

- React 19 + TypeScript
- Vite (빌드 도구)
- React Router (라우팅)
- Axios (API 통신)

## 환경 설정

`.env.example`을 복사해서 `.env` 파일 생성 후 서버 IP 입력:

```bash
cp .env.example .env
```

```
VITE_API_BASE_URL=http://YOUR_SERVER_IP
```

## 실행 방법

```bash
npm install
npm run dev
```
